# TrendTribes

A minimal, performant custom WordPress theme designed for WooCommerce to help you launch an ecommerce site quickly and efficiently.

## Features

- ⚡ Lightweight and fast-loading
- 🎨 Clean, modern, and customizable design
- 🛒 Seamless WooCommerce integration
- 🧩 Minimal dependencies and bloat
- 💡 Easy to extend with custom templates and hooks

## Prerequisites

- WordPress
- WooCommerce plugin

## Installation

1. Download or clone this repository:
   
   ```sh
   git clone https://github.com/gabrielepedesini/trendtribes.git
   ```
3. Copy the theme folder to your WordPress `wp-content/themes/` directory.
4. In your WordPress admin panel, navigate to **Appearance > Themes** and activate *TrendTribes*.

### Customization

- Modify theme templates (PHP files) to fit your needs.
- Add custom styles in the `style.css`.
- Use hooks and WordPress Customizer for further customization.
